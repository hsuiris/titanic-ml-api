02

資料前處理 Data Preprocessing

原始資料無法直接輸入模型。以下為實際套用的三種處理，每張卡片可展開對應程式碼，並可即時試算數值前後的變化。

① 缺失值填補

# 數值用中位數、類別用眾數填補
from sklearn.impute import SimpleImputer
num = SimpleImputer(strategy="median")
cat = SimpleImputer(strategy="most_frequent")
範例：某位乘客 Age = 空值 → 填入全體中位數 28。

② 類別編碼 One-Hot

— 欄
「維度」指模型實際輸入的欄位數。8 個特徵中有 5 個是類別欄位，One-Hot 把每個類別值各自拆成一個 0/1 欄位後，總欄數從 8 增為 18。
# 把類別轉成一堆 0/1 欄位
from sklearn.preprocessing import OneHotEncoder
OneHotEncoder(handle_unknown="ignore")
Sex = "female" → Sex_female=1, Sex_male=0
Pclass = 3 → Pclass_3=1，其餘為 0
維度＝3 數值欄 + Pclass(3) + Sex(2) + Embarked(3) + Title(5) + IsAlone(2) = 18

StandardScaler
套用在 Age、Fare、FamilySize
→ — 
# z = (x - 平均) / 標準差
from sklearn.preprocessing import StandardScaler
StandardScaler()

03

特徵工程 Feature Engineering

從原始欄位衍生三個新特徵。下方以各類別的生還率，佐證這些特徵確實帶有生還訊號。

Title 從姓名抽出稱謂
FamilySize 同行人數分組
IsAlone 是否獨自搭船
這三個衍生特徵都與生還率高度相關：Master（多為孩童）以及 2 到 4 人的小家庭 生還率明顯偏高， 是 SibSp、Parch、Name 等原始欄位單獨無法呈現的訊號，為後續模型提供了額外的判斷依據。

06

模型評估 Model Evaluation

最佳模型在測試集上的完整評估指標。

訓練後顯示。
混淆矩陣（測試集）

混淆矩陣怎麼讀

將模型在測試集上的判斷對錯攤開檢視。左上、右下為正確（實際未生還判為未生還、實際生還判為生還）；右上為「誤判生還」（實際未生還卻判為生還），左下為「漏判」（實際生還卻判為未生還）。對角線數字越集中，準確率越高。

ROC 曲線

ROC 曲線怎麼讀

橫軸為誤判率（實際未生還被判為生還的比例），縱軸為召回率（實際生還被正確判出的比例）。曲線越靠近左上角越好，對角虛線代表隨機猜測的基準。

特徵重要度 Feature Importance

最佳模型中，各特徵對預測生還的貢獻程度（相對重要度，數值加總約為 1）。

訓練後顯示。

數值是相對重要度（已正規化，全部特徵加起來約為 1，所以每個值大致代表它的佔比）。來源是模型內建的重要度：樹模型用 feature_importances_、線性模型用係數絕對值。像 SHAP 這類更進階的解釋方法可作為後續延伸。
